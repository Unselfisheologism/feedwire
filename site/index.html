An agent hits an error, works around it, or gives up.
Your logs may catch the failure. They don't tell you what the agent was trying to do. Feedwire gives it a place to say so.

A small addition to your backend

An endpoint, not another platform.

Add the middleware to your existing app. Agents can discover it at /.well-known/feedback.json and read the schema at /feedback/schema.

Express

Node 22.5+
const { feedback } = require('feedwire');
app.use(feedback({
  dbPath: 'feedback.db',
  adminToken: process.env.FEEDBACK_ADMIN_TOKEN }));

Install: npm install feedwire

FastAPI

Python 3.9+
import os
from feedwire import create_feedback_router
app.include_router(create_feedback_router(
  db_path="feedback.db", admin_token=os.environ["FEEDBACK_ADMIN_TOKEN"]))

Install: pip install feedwire

These snippets assume an existing app. Set a long, random FEEDBACK_ADMIN_TOKEN in your server environment. SQLite stores the reports. Feedwire 0.1.0 is available on npm and PyPI. Full setup instructions ↗
